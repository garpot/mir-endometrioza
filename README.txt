МИР ЭНДОМЕТРИОЗА — первая версия сайта

1. Распакуйте архив.
2. Загрузите все файлы и папку (если появится) в корень репозитория mir-endometrioza.
3. В GitHub откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку main и папку /(root), затем Save.
6. Через несколько минут сайт будет доступен по адресу:
   https://garpot.github.io/mir-endometrioza/

Файлы:
- index.html — главная страница
- about.html — об эндометриозе
- symptoms.html — симптомы
- diagnosis.html — диагностика
- treatment.html — лечение
- fertility.html — фертильность и беременность
- research.html — исследования
- sources.html — источники и редакционная политика
- style.css — оформление сайта

Перед публикацией проверьте ссылки и медицинские тексты. Это информационный проект, а не замена консультации врача.
